## Project Description
This repository houses the Next.js frontend application for the ECA Campus Management System. It consumes the backend microservices via the Spring Cloud API Gateway. The frontend is deployed as a Platform as a Service (PaaS) solution using **Google Cloud Run**. The deployment lifecycle is fully automated via GitHub Actions (CI/CD) and authenticated securely using Workload Identity Federation (WIF).

## Technology Stack
- Next.js
- React
- Tailwind CSS
- Docker
- GCP Cloud Run
- GitHub Actions (CI/CD)
- Workload Identity Federation (WIF)
